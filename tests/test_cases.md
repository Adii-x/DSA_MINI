# Manual Test Cases
1. Display the default food menu.
2. Add a valid food item.
3. Try an invalid price or negative stock; it should be rejected.
4. Place a valid order and note the token.
5. Search by token and verify the details.
6. Place two orders and verify the first is processed first.
7. Cancel a pending order and verify stock is restored.
8. Try cancelling a completed order; it must be rejected.
9. Display all orders and cancellation history.
10. Exit and restart; data resets because file handling is not part of this project.
